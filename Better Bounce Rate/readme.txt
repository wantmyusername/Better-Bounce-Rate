Radically improve your website's bounce rate with Better Bounce Rate!


== Description ==

This plugin offers you a quick and effective solution to reduce your website's bounce rate in just two simple steps: set up and forget it.


Also you can use different languages. To change language you need to generate .po and .mo files.

= Features =
* Easy Setup: Easily configure the minimum event time required to trigger the bounce rate.

* Complement Your Analytics: Allow additional code integration for deeper analysis in Google Analytics.

* Dashboard Status: Stay informed about the status of Better Bounce Rate directly from your admin panel.

* Total Customization: Adjust settings according to the specific needs of your website.

* Translation Compatible.

== Installation ==

1. Upload and extract 'zip' to the '/wp-content/plugins/' directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Add your Google Analytics Tracking ID code by navigating Settings >> Better Bounce Rate
